# Contexto bibliográfico

[English](LITERATURE_CONTEXT.md) · [Bibliografía de 53 referencias](REFERENCES.md)

ChronoWitness complementa los diseños de estímulos y la estimación de parámetros con una predicción compartida, uniforme en los parámetros, para una clase especificada de lectores periódicos. La aplicación a una señal medida requiere calificar su capa de observación.

El [trabajo de formación de patrones de 2020](https://doi.org/10.1038/s41467-020-15166-3) acopla células a señalización computada. El [trabajo sobre transmisión temporal de MAPK/ERK de 2023](https://doi.org/10.1371/journal.pcbi.1011155) aporta contexto experimental. El [control predictivo de 2024](https://doi.org/10.1038/s41467-024-46361-1) demuestra realimentación a escala de miles de células individuales. [CytoTape](https://doi.org/10.1038/s41586-026-10156-9) registra dinámica de regulación génica durante semanas. Los objetivos de observación y control difieren entre estos trabajos. ChronoWitness aporta identidades temporales exactas y condiciones inferenciales explícitas para una clase de lectores. La validación celular pareada FD7/FD8 permanece abierta.

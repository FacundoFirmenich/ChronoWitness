# ChronoWitness v0.12.0

The observation study now connects certified kinetic models to continuous-time paths, finite reporter acquisition and sequential power. A frozen Monte Carlo campaign is checked against independent moments and exact first-crossing references. Every declared setting includes its uncertainty intervals and seed counts.

Calibration-aware endpoint bounds quantify how rate and endpoint uncertainty consume separation. A prospective schedule exporter and bounded-block analyzer make the application requirements explicit. New guides connect the results to assay design and primary literature.

The code remains MIT. This distribution contains code and computational data; academic documents are maintained separately. Historical releases retain their original bytes and licenses.
